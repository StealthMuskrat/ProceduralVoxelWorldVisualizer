# Searchable World stage boundaries

Status: **uncompiled and untested** on `codex/development-phase` under the owner testing pause. The validated baseline remains 922 tests / 120 suites. This extends the existing [authoring and stage previews](AUTHORING_AND_STAGES.md) and [selector decisions](SELECTOR_DECISIONS.md); it does not advance A01–A36 or production sign-off.

World Boundary now uses the existing searchable, clipped local-choice popup rather than submitting every layer/operation in one combo. Rows carry UUID keys, resource kind/ID, parent layer ID and effective enabled status. Search includes labels, parent labels, status and full UUIDs; long/native-control text uses the established UI text escaping and tooltip path. Disabled layers and placements remain selectable stage boundaries, matching the engine's equal-prefix semantics. The catalog groups each layer and its ordered operations in authored pipeline order, independent of resource-tree presentation order. This is grouping for selection; the engine's stage enumeration still lists operation intervals before the containing layer interval.

StageBoundaryCatalog freezes row values and precomputes choices once per committed project object/revision. Unchanged native frames reuse the same catalog. Properties selection is consulted only when a boundary has never been selected: a matching layer/operation UUID wins, otherwise the first layer is the initial choice. A missing explicit UUID remains selected and unavailable, allowing Undo or an explicit replacement instead of silently choosing another stage. Final needs no boundary, and an empty project does not invent one.

StageBoundaryPicker binds popup opening ownership to preview mode plus the existing document lifetime, project/revision, selected UUID, immutable rows and raw query. Escape, mode changes, hidden frames, reopening and same-UUID document replacement retire predecessor choices. Row callbacks run only after popup/child/clipper/native ID cleanup; the existing selector's bounded failure diagnostic and explicit owned retry remain authoritative. Selecting a stage changes only World view state and never applies a Properties draft or edits the project.

Viewports initializes only never-selected boundaries and routes accepted UUID changes through the existing preview invalidation. With a missing or empty non-Final boundary, it stops the old stream and returns before accepting/submitting/rendering a replacement preview. It retains existing GPU buffers for ordinary recovery but does not present them as the unavailable boundary. The stage control offers actionable recovery text. Independent Inspect Coordinate remains available. Picking also rejects an unavailable boundary; its immutable worker snapshot now requires an exact non-Final engine stage instead of treating lookup failure as Final. The engine API, stage intervals, procedural output and project schema are unchanged.
