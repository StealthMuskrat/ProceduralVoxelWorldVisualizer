# Pinned control browsing and source focus

Status: **implemented, awaiting validation** on `codex/development-phase`. GitHub testing remains paused by owner instruction until the program is fully developed. This source and its regression/native/independent replay definitions have not been compiled or executed.

The existing Pin shape and canonical shared/item references are unchanged. The compact Pinned Controls group now filters exact authored groups and uses cached searchable/clipped choices. All groups, Ungrouped and actual groups named those strings have distinct transient keys. Filtering does not reorder pins, change values or replace the selected pin. A selected pin outside the current filter stays visible in the editor with an explanation; the picker shows only matching choices.

Selection belongs to the exact Pin object in one private Noise draft. Transient picker tokens remain attached to that object across metadata edits and reorder, and are not array indices or persisted identities. Deleted tokens cannot select removed pins. A replacement draft, including one with the same UUIDs and pin metadata, gets new tokens and selects its own first pin. Unpin chooses an actual neighboring entry. Groups/rows are rebuilt on explicit draft edit versions and reused on ordinary frames; tokens for removed pins are released. Only one draft's catalogue is retained.

Pin label/group text has separate widget buffers from the original Properties controls. Switching pins does not clear the source editor's provisional text. Editing a pinned shared parameter changes its original typed value directly; no value is stored on the pin. Item pins remain source links, show up to eight current input-source descriptions, and offer exact named-input navigation. Source descriptions resolve current UUID references and names without evaluating a field. Longer descriptions are bounded. Additional inputs remain accessible in the original item editor.

**Go To Control** now routes shared parameters to their actual typed Value, Constant items to Value, Curve items to the private curve editor, and other bound items to their primary available named input. A Used By pin link, or an explicit `pin/label`/`pin/group` destination, opens Pinned Controls and focuses metadata when the control UUID identifies exactly one current pin. Duplicate references and historical pin array positions reveal the picker without guessing an entry. Changed/replaced pin objects or retargeted references cancel a pending pin-field request. Missing references remain visible and removable in the provisional panel.

Labels, groups, order and Unpin remain presentation changes and do not alter computation identity. Filtering/navigation does not commit, save, dirty the project or enter history. Properties Apply remains one complete noise-resource transaction; Undo/Redo includes both pin metadata and any explicitly edited canonical parameter value. No engine/compiler, persisted Pin field, schema or public API changes are introduced.
