Creation default is optional and selected on each fresh opening. With built-in metadata this creates OpenSimplex2, seed offset zero, no transforms/processing/shared parameters/pins and raw source Scalar output. Selecting an algorithm overrides the profile's source key for this resource while using that chosen algorithm's dimension-specific parameter defaults and the existing seed default. Switching to an analytic source does not carry another algorithm's parameters. Choosing Creation default again removes the local choice. Changing the choice or cancelling creates no resource and does not alter metadata or an existing definition.
