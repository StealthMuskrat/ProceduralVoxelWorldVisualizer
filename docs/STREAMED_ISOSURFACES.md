# Camera-relative isosurfaces

Isosurface now joins Threshold Voxels and Point Cloud in the normal camera-relative streaming path. Explicit Fixed analysis retains the bounded float-mesh path. View navigation preserves the compiled source epoch; definition, selected source or threshold changes create a new one. Streaming continues loading nearby chunks during manual regeneration mode without changing the source snapshot.

Surface chunks own immutable `(size+1)^3` canonical corner grids. They sample complete shared faces independently at identical global coordinates, including signed origins. Meshing uses the bounded/cancellable marching-tetrahedra extractor. It needs no neighbor halo or display-mask remeshing: each chunk already owns its complete corner boundary. Source data, mesh reservations, cache/entry counts, worker admission, cancellation, epochs and upload completion use the existing ChunkScene lifecycle. Failed/mismatched sources do not publish partial geometry. Surface CPU admission retains an explicit budget reason.

The packed arena adds surface positions at 1/128 block while retaining the existing 16-byte vertex layout; voxel/point meshes keep half-block units. Surface coordinates round to the nearest grid location (maximum 1/256 block error per axis), normals use signed normalized bytes, AO is fully lit and material remains the surface palette entry. Triangles that collapse under quantization are omitted. This is display precision, not a change to procedural samples or exact voxel data. Fixed analysis provides finer positions. Surface detail stays at the full sampled grid; voxel majority LOD is not applied to scalar surfaces. Pressure still reduces view distance/preload, defers work and pauses when needed.

GPU residents retain their position units through incremental upload and arena compaction. Fallback and indirect draws group by primitive type and position units, setting the matching decode scale for each batch. No surface becomes drawable before its whole upload completes. Surface meshes do not provide occupied-voxel picking cells; World inspector behavior remains on voxel scenes.

CPU tests cover canonical corner counts/cache reuse, exact shared quantized faces, cancellation, finite/domain checks, no artificial caps, packed precision/root 256, immutable ownership, signed camera travel, memory rejection, queue recovery, closure and source-layout mismatch. Native checks mix surface and voxel meshes in one arena, enforce upload/relocation limits, compare indirect/fallback/compacted pixels, and replay a packed plane's area and attributes independently. A production Viewports fixture travels through positive and negative chunks without rebuilding the source epoch, enters fixed analysis, returns to a fresh streaming epoch and checks rendered pixels and project/history invariance.

Streaming volumes, coarser scalar-surface LOD, representative performance/quality measurements and full GUI/DPI/Windows 11 hardware acceptance remain separate.
