# Visualizer toolbar and context commands

Status: **uncompiled and untested** on `codex/development-phase` under the owner testing pause. The validated baseline remains 922 tests / 120 suites. This follows [bookmark decisions](BOOKMARK_DECISIONS.md), [stage boundary selection](STAGE_BOUNDARY_SELECTION.md) and the existing [image gestures](IMAGE_GESTURES.md). No A01–A36 or production sign-off advances.

ViewportCommands now draws the complete Regenerate/Auto toolbar before accepting at most one action, with Regenerate first in displayed order. Escape suppresses both. A per-instance presentation scope owns the exact document lifetime/project/revision, view/tab, source epoch, generator/stage UUIDs, display/stage modes, native surface value, bookmark dialog identity, Auto/Grid values and picked coordinate. It rechecks a live supplier after complete drawing. A changed source or omitted/native-restarted frame versions the action IDs; failed unchanged callbacks keep an explicit retry available. Independent instances serve the three tabs. The Auto control wraps using its actual checkbox frame/text width, and preview status uses wrapped text.

The context popup owns an explicit opening, native parent host and the same immutable review. Row IDs include a per-instance opening version while popup and scrolling child identities remain stable. Escape, changed source, skipped frame or another native host closes the predecessor without executing a command. All available menu items are collected first; the first accepted command consumes the opening, closes the popup and unwinds child/ID/popup scopes before invoking its callback. A callback may open a bookmark dialog or another context popup; predecessor cleanup cannot close that successor afterward. A failed command records a bounded required VIEWPORT_COMMAND_FAILED diagnostic. The user explicitly reopens a failed menu; callbacks never replay automatically.

The menu uses PopupLayout work-area fitting and one scrolling child, retaining all nine 2D or three 3D/World commands at large font scales. Menu rows may lie outside the visible child until scrolled; the deferred geometry checks do not equate row submission with physical reachability. Existing short-right-click gesture admission, 2D/slice accepted-coordinate capture, native platform focus and camera navigation remain authoritative. Camera position and worker progress alone are outside command ownership: Regenerate applies to the latest view of the same source, and Teleport uses the existing guarded current-coordinate getter. Add receives the reviewed picked coordinate. Source epoch changes, picked-coordinate replacement and source/document changes retire the opening.

Viewports routes accepted commands to its existing regeneration invalidation/rebuild serial, display mode, active Grid setting and BookmarkPanel opening methods. No generation/model API or project transaction changes. Auto now uses an owned UserConfig snapshot: validate and atomically write the latest preferences with only autoRegenerate changed, then publish that Boolean. Failed validation or replacement leaves the active value unchanged, making the same checkbox action an explicit retry. Unrelated active preferences are retained. Grid keeps its existing active-preference authority; no project save is introduced.
