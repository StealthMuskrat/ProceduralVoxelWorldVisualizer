Development implementation on main; **uncompiled and untested** under the owner's testing pause. No compiler, Gradle, JUnit, native probe, independent consumer, checker, packaging operation or workflow ran. The observed baseline remains **922 tests / 120 suites**. ## Share canonical fields within one world plan

WorldPlan previously constructed a new NoiseCompiler for every enabled placement. Each compiler copies the complete source model and owns its own compiled-resource/dependency map. Repeating the same canonical field under the same effective seed therefore repeated model copying and field/dependency compilation, even when only placement transforms or interpretation differed. The constructor comment had incorrectly implied that per-operation copying was already avoided.

WorldPlan now keeps a construction-local compiler map keyed by effective seed. The seed calculation is unchanged: a zero resolved placement seed offset uses the context seed directly; other offsets use `mix(contextSeed XOR resolvedOffset)`. Each distinct effective seed creates one compiler. The existing compiler UUID cache then reuses canonical resource/dependency executables for primary fields, gates and drivers requested through that compiler. Disabled layers/placements create no entries. The map is bounded by the number of distinct enabled-placement seeds and is not a global or cross-context cache.

This key is sufficient because the source definition is fixed for a WorldPlan. Each placement still resolves its own Settings, sampling program, drivers, interpretation, target, provenance and work attribution. Coordinate transforms run outside the canonical field evaluator. Probability retains its existing noise/placement seed and UUID/world-coordinate hash; a shared field does not share a draw or voxel state. No sampled-value cache is added across placements. Existing field executables use per-thread work buffers and begin a new sample epoch on each call.

Each new WorldPlan builds its own compiler map, including another context with the same seed. Context caches, requests, cancellation and storage remain independent. Direct public noise samplers and low-volume diagnostic explanation replay keep their existing compilation paths. No changes are made to snapshot admission, exception ownership, schemas, registries, public signatures, numerical evaluation order or serialized formats.

This removes source-visible redundant construction; it is not a measured speedup or memory guarantee. Representative compilation/heap measurements and the wider W05 API/plan/scheduler/cache/archive audit remain deferred. Unique seeds still need separate compilers, and the existing compiler still captures all canonical definitions before compiling the reachable resources it needs.
