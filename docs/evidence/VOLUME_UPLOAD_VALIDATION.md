# Bounded volume texture replacement

Validated implementation: `130e2f10b864d0e935e0d0cf40a8afa60c0ccd99`.

[Actions run 40581850124](https://github.com/StealthMuskrat/ProceduralVoxelWorldVisualizer/actions/runs/40581850124) passed Linux, Windows and cross-platform JAR reproducibility with Temurin 25.0.4+7 and Gradle 9.2.1. Both platform builds passed `clean test build dependencyNotices releaseJars`, prior native workflows, independent references and packaged launcher checks. Raw Linux JUnit contains **861 tests across 112 suites, zero failures/errors/skips**; see [summary](volume-upload-junit.json). Both platforms record VOLUME_UPLOAD_NATIVE_PASS / VOLUME_UPLOAD_PASS.

Volume previews previously cloned all encoded samples and uploaded a complete texture in one render-thread call. The editor now admits an active/candidate scalar texture pair and copies only bounded contiguous regions through reusable 64 KiB staging. Per-frame destination writes obey Upload KiB, including partial rows. Complete textures publish with matching encoding, extent, origin, palette and hover metadata. Cancellation, replacement, admission rejection and upload failure preserve accepted data. See [upload lifecycle and API](../VOLUME_UPLOADS.md).

Seven new memory-backend contracts independently reconstruct every 3D write for sides 2, 3, 17, 32 and 65 under random budgets, including budgets smaller than one texel/row/plane. They cover complete-only publication, exact inclusive active/candidate GPU admission, rejection before allocation, replacement/cancellation, allocation/write failures, a failure after a successful region, cumulative/per-frame submitted-byte accounting, candidate cleanup, idempotent closure, immutable samples and invalid buffer ranges. Existing admission boundary contracts now include staging in volume working bytes: 12 bytes per cell plus 65,536 bytes. Profiler CPU data includes held staging and pending samples.

The native GL fixture uploads a 17-cube X-gradient with a 79-byte advance budget. Its 259 advances submit **19,652 bytes**, at most 76 per advance. Every one of **4,913 encoded float texels** matches GPU readback exactly. The analytical center path has normalized density .5, length 17 and opacity .1, giving transmittance exp(-.85). The observed RGBA pixel is [152,8,11,255], within the unchanged two-channel-unit tolerance. Independent Python compares float32 encodings, byte sums and Beer-Lambert optics; it also replays the complete prior World-picking report family.

Incomplete uploads retain the entire prior framebuffer even when a new render size is requested. The probe sets nondefault unpack alignment, row/image strides, XYZ skips and byte swapping while a pixel-unpack buffer is bound; every upload restores those values. It checks admission rejection, accepted-texture retirement, cancellation and closure. A real streamed voxel scene remains visible on rejected admission and after its arena is retired by a subsequently canceled candidate. This transition guard was added during review; no assertion was weakened.

The production Viewports fixture compiles constant filled/empty fields from the [saved project](volume-upload-project.json), with Upload KiB=16. It accepts a 32-cube at origin [0,0,0], begins a replacement at another origin, verifies retained accepted metadata/pixels, cancels it and accepts a 16-cube at [-24,-24,-24]. A 256-cube request is rejected by the 16 MiB GPU cap before source sampling. Retrying a smaller request accepts origin [32,32,32]. Accepted texture versions are exactly [1,2,3], with no canceled/rejected publication. Maximum frame writes are 16,384 bytes. Authored JSON, revision and Undo bytes remain unchanged. See [raw texels, pixels, bytes and state report](volume-upload-native.json).

The [Linux evidence artifact](https://github.com/StealthMuskrat/ProceduralVoxelWorldVisualizer/actions/runs/40581850124/artifacts/12769508079) retains complete raw XML and native outputs. The final evidence commit also clarifies Profiler wording: total GPU data can include scalar textures, while vertex-arena allocation remains a separate quantity. This is fixed-volume upload evidence, not a streaming volume atlas or latency certification. Scalar texture admission covers active and candidate texels; framebuffer/depth attachments, fixed mesh buffers and driver overhead are outside it. Texture allocation can still incur driver latency, and byte submission is not GPU completion time. Full physical input/DPI, arbitrary device failures, representative performance and Windows 11 hardware remain separate; A28/A31 remain PARTIAL. Canonical samples, headless engine APIs, project schemas and archive formats are unchanged. The synchronous GlViewport.setVolume API remains available beside explicit stage/advance/cancel methods.
