# World Properties numeric controls

Status: **uncompiled and untested** on `main`. The owner testing pause remains active, the workflow remains manual-only, and the observed baseline remains 922 tests / 120 suites. This follows [noise numeric controls](NOISE_NUMERIC_CONTROLS.md) and covers source implementation in specification 4.1.2/4.3.3/10.2–10.4, supporting A08/A16/A32 without changing acceptance results.

All numeric inputs in World Properties now use measured slider/text pairs: layer scalar defaults, explicit placement overrides, inclusive min/max Y, gate thresholds/intervals/probability, field and numeric driver endpoints, one-based transform targets, type intervals, and ordered sampling-transform components/pivots. The input sits to the right when both fields fit and stacks below at narrow widths or larger fonts. Existing property/binding wrappers still focus the exact input after the slider. Named choices, Boolean controls and exact signed-long seed editors retain their existing paths.

Slider suggestions use [0,1] for strength/probability and unit driver outputs; [-1,1] for thresholds, gates, intervals and driver inputs; project Y bounds for base height and min/max Y; [-256,256] for height scale and signed numeric-driver outputs; [-8,8] for scale; and [-1024,1024] for offsets/pivots. Sampling rotations suggest [-180,180] degrees. A one-based transform target suggests existing rows, or row 1 when the list is empty. These bounds do not clamp existing or typed values or replace engine validation. Signed scalar values and explicit zero remain authorable wherever the existing engine permits them.

UiFields shares the same slider implementation between scalar and integer rows. Integer gestures use a double intermediate, which exactly represents all signed ints, while their adjacent input remains InputInt. Initial minY/maxY sentinel values remain exact even when outside the suggested project interval. Scalar sliders retain NoRoundToFormat and disable native temporary rounded text entry. Scalar text retains the [existing precision policy](NUMERIC_EDITOR_PRECISION.md); universal five-place exact-edit presentation remains outside this claim. Non-finite private values produce a disabled slider labelled Invalid, using a finite display placeholder only inside that widget. The original NaN/infinity still reaches the exact input and existing Apply validation, allowing keyboard repair without feeding non-finite geometry to the slider.

Inherited placement settings continue to show their resolved layer value and explicit Override action. They do not draw editable numeric rows or store resolved copies. Only an enabled override draws its numeric pair. Reset removes that key from the private map; Apply publishes the removal as one transaction. Layer edits update live inherited values without changing sparse overrides, reusable source definitions, other resources, preferences, model/schema or engine/public APIs. Ordered transform/driver/interval properties retain their established atomic-list inheritance and ordering.
