# Engineering decisions and current limitations

## Fixed implementation contracts

- Project format 2 is explicit. Model objects serialize ordered arrays, stable UUID references, and exactly one World Generator. Noncanonical visible IDs are rejected, with case-sensitive NFC comparisons. Unknown JSON fields, duplicate object keys, malformed UUIDs and unsupported versions are rejected. Enabled noise definitions receive compiler validation before the editor or public ProjectLoader accepts them.
- `project-model`, `engine-core`, `voxel-storage`, and `engine-api` contain no desktop/OpenGL dependency. The separately assembled engine JAR is exercised by an external javac/java invocation.
- New layer defaults are NO_CHANGE. Placement overrides use map presence; zero remains an override, null is invalid, reset removes the key. A placement never mutates its source resource.
- Same-cell world predicates allow per-cell execution of immutable stages without observing partial writes. A voxel sees earlier operations only. Field-selection gates and voxel predicates have separate types and evaluators.
- Root storage is an immutable int arena and per-chunk runtime dictionary: EMPTY and UNIFORM are immediate encodings, branches have eight child indices, and heterogeneous leaves up to 4³ choose local palette bit packing or a dense primitive fallback. Inclusive immutable bulk fill/clear coalesces adaptive regions without root-sized dense staging. See EXACT_STORAGE.md.
- CoordinateHash uses SplitMix64 finalization. Operation probability includes stable operation identity and effective seeds, never traversal or worker identity. 2D placement fields are cached per X/Z during chunk generation.
- FastNoiseLite 1.1.1 was vendored with its original notice. Upstream's marked coordinate declarations use double; outputs remain the reference float values widened to double. Exact cross-architecture certification has not been completed.
- Expression operators/functions use immutable compiled nodes and per-thread scratch. Numeric domain errors fail at the executed boundary. Short-circuiting is real; invalid unselected ternary/Boolean branches are not evaluated. Power is right-associative and binds above unary minus. Enabled items are validated even when not selected; execution prunes unused processing results. Valid pure numeric/Boolean/vector constants and constant Select/AND/OR results are folded. Expressions now compile to bounded lazy register plans with constant folding, branch pruning, indexed inputs and successful-value sharing. Compatible pure processing items share successful results while retaining each executing item’s error boundary. Primitive strided grids/point batches provide checked addressing and cancellation. See COMPILED_EXPRESSIONS.md.
- Curve Smooth uses monotone-limited Hermite slopes; Bezier uses explicit endpoint slopes and one-third X handles. Step is left-valued within a segment and exact knots use that knot's value. Outside-domain policies are explicit; raw outputs are never implicitly clamped.
- Generation queues and region in-flight windows are bounded. Separate virtual coordinators may wait for async consumers without occupying generation workers. Completed immutable snapshots survive cancellation, cache eviction and context closure.
- Archive v2 stores a semantic string dictionary, compressed palette-packed adaptive roots, explicit sparse coverage and a checked random-access index. Readers retain v1 compatibility and writers offer explicit LEGACY_V1 output. EMPTY coverage and absent coverage differ. Decoding rejects unresolved required IDs without mutating the registry.
- Properties use an isolated draft and Apply/Revert. Valid Apply is one document transaction. Undo/Redo uses bounded structural value/array-splice delta history; navigation and preferences are outside it. Saves stage a sibling file, force contents, then use atomic replacement where available.
- The renderer uses camera-relative float matrices derived from double navigation, packed halo-aware AO meshes and multirow GPU palettes. Display-only palette, folder and bookmark edits preserve the computational source identity.
- Free-fly camera mode and native cursor capture are separate. World picking suspends capture/input for the Inspector without converting the camera to orbit. Ineligible closure, focus loss and tab changes stay paused until explicit Ctrl-click resume; Escape in an eligible viewport returns to orbit with the same eye/orientation. See FREE_FLY_AND_INSPECTOR.md. Physical-input/DPI/OS focus-loss and full GUI acceptance remain separate.
- Orbit gestures own their image press and original camera pose, continue outside that image and cancel on focus/tab/popup/external navigation. Escape rolls back; short-click movement/time bounds prevent pans, long presses and out-and-back drags from becoming picks or context menus. Middle axes lock at press time. See ORBIT_GESTURES.md. Navigation remains outside project/history state.
- Orthogonal slices use their requested plane-local centers independently of orbit/free-fly Y position. Left/middle pans own their original request/image dimensions and wheel zoom anchors the requested world point. Accepted pixels retain immutable geometry and sampler for hover/bookmarks during pending edits or manual regeneration. See SLICE_NAVIGATION.md. Navigation remains outside project/history state; physical input/focus/DPI and full GUI acceptance remain separate.
- 2D pans freeze press-time image dimensions through resize and apply final-release movement. Owned short left clicks alone replace picked coordinates; collapse/focus/cancellation cannot resume a held predecessor. 2D and slice menus share sticky short-right-click ownership, and image pointer normalization uses accepted geometry in double precision. See IMAGE_GESTURES.md. These are view interactions outside project/history state.
- World, Threshold Voxels and Point Cloud previews use camera-driven chunk streaming with bounded jobs, CPU/GPU budgets, LOD hysteresis, exact boundary shells, frustum culling, incremental arena uploads, indirect/fallback draws and ordered pressure controls. Isosurface previews stream cached canonical corner grids with unit-face-preserving display LOD and 1/128-block packed positions; fixed analysis retains full-grid float geometry. Volume also streams bounded moving texture windows with reusable canonical chunks and explicit fixed analysis; slices retain bounded fixed analysis. See STREAMING_AND_LOD.md. The internal editor runtime uses fixed size 32 after the recorded sparse/dense/mixed/high-frequency comparison in docs/evidence/BENCHMARK.md. This local measurement is not a universal hardware certification.

## Outstanding requirements preventing production sign-off

The original specification is much broader than the current tested development implementation. Do not mark A01–A36 complete from a compiling build. Remaining work includes:

- Complete GUI acceptance of typed manipulation and warp controls; validate expanded semantic-input/result sharing and measure representative batch performance. Typed sampled-field prefixes, all six intermediate types, explicit dimension conversions and coordinate-stage input bindings now have mathematical/ordering/short-circuit tests. See FIELD_PROCESSING.md.
- Expand independent source vectors to more parameter/domain cases and complete the certified JVM/CPU matrix. The 3,264-case upstream C++ corpus, 240 exact analytic/hash vectors, 32 exact seed vectors and 20 pinned Linux/Windows JVM digests are scoped evidence; see SOURCE_ALGORITHM_CONTRACTS.md.
- Complete GUI acceptance of mixed root ordering, World folders, sibling clipboard, inline F2 rename, atomic replacement/deletion and portable COPY/REUSE/SKIP previews.
- Complete interactive GUI acceptance of the curve editor. Multi-point cumulative snapping, one-entry gesture history, Auto/Aligned/Free validation, tangent drawing/dragging and configurable display ranges are implemented.
- Full interactive Tree 10 acceptance and validation of the newly implemented indexed transform-component destinations. Phased sampling-scale/offset, strength/probability and threshold/base-height/height-scale mappings now support REPLACE/ADD/MULTIPLY, atomic inheritance and per-row traces; see NUMERIC_PARAMETER_DRIVERS.md. Interval type sources, mapped strength/probability drivers, signed axes/ordered sampling transforms and NOT/probability gates are implemented; see WORLD_USE.md.
- Region counts beyond signed long capacity and chunks beyond signed 32-bit block coordinates are explicitly rejected. Same-context sharing, immediate explicit-token cleanup, weighted queued priorities, per-lane context fairness, global automatic cache reclamation and protected USER_MANAGED ownership are implemented. Broader scheduler/consumer race and hardware-load coverage remain; see SCHEDULING_AND_CACHE_ADMISSION.md.
- Complete interactive trace/streaming acceptance, validation of newly implemented specialized input/control focus routing, and full expression GUI acceptance. Exact Before/After/Only Changes snapshots and UI, removal ghosts, stage-aware picking and effective/gate/probability traces are implemented. Exact DDA picking is implemented and tested.
- Broader streamed-volume pressure/performance coverage, validation of newly implemented coarse display sampling and resident-volume self-shadowing, representative hardware performance measurements and full GUI acceptance of the implemented renderer/pressure controls.
- Full interactive typed-item/resource/theme/profiler acceptance and broader representative hardware measurements. Bounded opt-in captures and explicit exports are implemented; optional bounded GPU_DRAW timestamp intervals now cover offscreen 3D commands; total GPU frame cost and hardware performance certification remain outside the capture contract. Structured grouped logs, independent notification attention state and UUID-scoped diagnostic navigation are implemented; validation of the new specialized control-routing implementation, full expression GUI acceptance and full manual recovery acceptance remain. See DIAGNOSTICS_AND_RECOVERY.md.
- Measured representative Windows hardware, full interactive GUI acceptance, complete third-party distribution review and owner-approved project license/redistribution notice.
- Final binary reproducibility verification, Windows 11 acceptance, and production release packaging sign-off.

Development artifacts and CI smoke tests are useful evidence but are not a claim of complete specification conformance.
