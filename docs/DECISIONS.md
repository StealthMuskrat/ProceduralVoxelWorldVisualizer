# Engineering decisions and current limitations

## Fixed implementation contracts

- Project format 2 is explicit. Model objects serialize ordered arrays, stable UUID references, and exactly one World Generator. Noncanonical visible IDs are rejected, with case-sensitive NFC comparisons. Unknown JSON fields, duplicate object keys, malformed UUIDs and unsupported versions are rejected. Enabled noise definitions receive compiler validation before the editor or public ProjectLoader accepts them.
- `project-model`, `engine-core`, `voxel-storage`, and `engine-api` contain no desktop/OpenGL dependency. The separately assembled engine JAR is exercised by an external javac/java invocation.
- New layer defaults are NO_CHANGE. Placement overrides use map presence; zero remains an override, null is invalid, reset removes the key. A placement never mutates its source resource.
- Same-cell world predicates allow per-cell execution of immutable stages without observing partial writes. A voxel sees earlier operations only. Field-selection gates and voxel predicates have separate types and evaluators.
- Root storage is an immutable int arena and per-chunk runtime dictionary: EMPTY and UNIFORM are immediate encodings, branches have eight child indices, and heterogeneous leaves up to 4³ choose local palette bit packing or a dense primitive fallback. Inclusive immutable bulk fill/clear coalesces adaptive regions without root-sized dense staging. See EXACT_STORAGE.md.
- CoordinateHash uses SplitMix64 finalization. Operation probability includes stable operation identity and effective seeds, never traversal or worker identity. 2D placement fields are cached per X/Z during chunk generation.
- FastNoiseLite 1.1.1 was vendored with its original notice. Upstream's marked coordinate declarations use double; outputs remain the reference float values widened to double. Exact cross-architecture certification has not been completed.
- Expression operators/functions use immutable compiled nodes and per-thread scratch. Numeric domain errors fail at the executed boundary. Short-circuiting is real; invalid unselected ternary/Boolean branches are not evaluated. Power is right-associative and binds above unary minus. Enabled items are validated even when not selected; execution prunes unused processing results. Valid pure numeric/Boolean/vector constants and constant Select/AND/OR results are folded. Expressions now compile to bounded lazy register plans with constant folding, branch pruning, indexed inputs and successful-value sharing. Compatible pure processing items share successful results while retaining each executing item’s error boundary. Primitive strided grids/point batches provide checked addressing and cancellation. See COMPILED_EXPRESSIONS.md.
- Curve Smooth uses monotone-limited Hermite slopes; Bezier uses explicit endpoint slopes and one-third X handles. Step is left-valued within a segment and exact knots use that knot's value. Outside-domain policies are explicit; raw outputs are never implicitly clamped.
- Generation queues and region in-flight windows are bounded. Separate virtual coordinators may wait for async consumers without occupying generation workers. Completed immutable snapshots survive cancellation, cache eviction and context closure.
- Archive v2 stores a semantic string dictionary, compressed palette-packed adaptive roots, explicit sparse coverage and a checked random-access index. Readers retain v1 compatibility and writers offer explicit LEGACY_V1 output. EMPTY coverage and absent coverage differ. Decoding rejects unresolved required IDs without mutating the registry.
- Properties use an isolated draft and Apply/Revert. Valid Apply is one document transaction. Undo/Redo uses bounded structural value/array-splice delta history; navigation and preferences are outside it. Saves stage a sibling file, force contents, then use atomic replacement where available.
- The renderer uses camera-relative float matrices derived from double navigation, packed halo-aware AO meshes and multirow GPU palettes. Display-only palette, folder and bookmark edits preserve the computational source identity.
- World, Threshold Voxels and Point Cloud previews use camera-driven chunk streaming with bounded jobs, CPU/GPU budgets, LOD hysteresis, exact boundary shells, frustum culling, incremental arena uploads, indirect/fallback draws and ordered pressure controls. Volume, slices and isosurfaces retain bounded fixed analysis. See STREAMING_AND_LOD.md. The internal editor runtime uses fixed size 32 after the recorded sparse/dense/mixed/high-frequency comparison in docs/evidence/BENCHMARK.md. This local measurement is not a universal hardware certification.

## Outstanding requirements preventing production sign-off

The original specification is much broader than the current tested development implementation. Do not mark A01–A36 complete from a compiling build. Remaining work includes:

- Broaden the manipulation registry and complete GUI acceptance of typed controls; expand conservative sharing coverage and measure representative batch performance. Typed sampled-field prefixes, all six intermediate types, explicit dimension conversions and coordinate-stage input bindings now have mathematical/ordering/short-circuit tests. See FIELD_PROCESSING.md.
- Complete per-algorithm independent reference vectors and certified JVM/CPU matrix.
- Broaden resource root cross-kind ordering and world-folder organization; complete GUI acceptance of sibling clipboard, inline F2 rename, atomic replacement/deletion and portable COPY/REUSE/SKIP previews implemented in the authoring batch.
- Complete interactive GUI acceptance of the curve editor. Multi-point cumulative snapping, one-entry gesture history, Auto/Aligned/Free validation, tangent drawing/dragging and configurable display ranges are implemented.
- Broader field-driven parameter destinations and full interactive Tree 10 acceptance. Ordered threshold/base-height/height-scale mappings now support REPLACE/ADD/MULTIPLY, atomic inheritance and per-row traces; see NUMERIC_PARAMETER_DRIVERS.md. Interval type sources, mapped strength/probability drivers, signed axes/ordered sampling transforms and NOT/probability gates are implemented; see WORLD_USE.md.
- Region counts beyond signed long capacity and chunks beyond signed 32-bit block coordinates are explicitly rejected. Same-context sharing, immediate explicit-token cleanup, weighted queued priorities, per-lane context fairness, global automatic cache reclamation and protected USER_MANAGED ownership are implemented. Broader scheduler/consumer race and hardware-load coverage remain; see SCHEDULING_AND_CACHE_ADMISSION.md.
- Broader trace-to-control navigation and full interactive streaming acceptance. Exact Before/After/Only Changes snapshots and UI, removal ghosts, stage-aware picking and effective/gate/probability traces are implemented. Exact DDA picking is implemented and tested.
- Streaming volume/isosurface display, shadows, arena compaction, representative hardware performance measurements and full GUI acceptance of the implemented renderer/pressure controls.
- Complete settings metadata creation-default controls, shortcut grammar, broader tree virtualization, theme contrast feedback and detailed bounded profiler captures. Structured grouped logs, independent notification attention state and UUID-scoped diagnostic navigation are implemented; broader control/trace routing and manual recovery acceptance remain. See DIAGNOSTICS_AND_RECOVERY.md.
- Measured representative Windows hardware, full interactive GUI acceptance, complete third-party distribution review and owner-approved project license/redistribution notice.
- Final binary reproducibility verification, Windows 11 acceptance, and production release packaging sign-off.

Development artifacts and CI smoke tests are useful evidence but are not a claim of complete specification conformance.

## Observed native evidence

Linux local software OpenGL smoke completed all three engine-backed viewports, save/reload and clean exit. Screenshots were inspected. GitHub Actions run 40045036266 also passed Linux and Windows Server 2025 native smoke with Temurin 25.0.4+7 and bundled Windows runtime/Mesa. This is not a Windows 11 hardware certification. The later pipeline adds packaged-launcher and cross-platform JAR hash verification.

The imgui-java 1.89 GLFW backend can attempt to destroy an unavailable X11 cursor (0). Desktop shutdown contains that specific failure and still disposes callbacks, contexts and GLFW. Other NullPointerExceptions are not suppressed. Multi-release JAR metadata is retained for LWJGL 3.4.1 Java 25 support.

Generation admission reserves a conservative 16 bytes per root voxel, 32 bytes per possible chunk palette entry (bounded by registry/root size), plus 2D field-cache storage, accounting for arena growth and immutable publication copies rather than only the final snapshot size. This may reject large concurrent roots before allocation even when the eventual sparse chunk would be small.

The GUI binding publishes additional Kotlin support dependencies through Gradle module metadata. kotlin-stdlib-jdk8 1.8.20 is explicit in the desktop runtime graph so POM-based local mirrors and online Gradle resolution produce the same complete runtime; its transitive artifacts are checksum verified. The headless engine graph remains free of GUI/Kotlin dependencies.

The first cross-platform comparison found identical per-file JAR hashes but a different manifest listing order: pathlib uses case-insensitive path ordering on Windows. Hash manifests now sort explicit filename strings, and fat-JAR input archives sort by name. The check compares artifact bytes, not platform-specific filesystem ordering.

Typed field compilation now distinguishes numeric results from Source Field, Earlier Field Prefix and Noise Generator Field selectors. Derivatives, filters, fractals and warps reevaluate actual procedural locations. Coordinate-stage snapshots use independent scratch slots and support typed inputs, pivots and explicit 3D axis order. Field-prefix work is bounded before evaluation; source/processing stage restrictions are validated. See [field semantics](FIELD_PROCESSING.md).

The 3D Noise viewport now ray marches an immutable GL_R32F scalar texture with normalized heatmap transfer, explicit display range, opacity per block, threshold and 16..512 ray steps. Samples are cell-centered canonical double evaluations; conversion to float is display-only. Front-to-back Beer–Lambert compositing stops at low transmittance. CPU tests verify texture order and affine trilinear reconstruction. A native numerical probe compares homogeneous absorption, threshold rejection and a linear gradient with analytical pixel values, including switching between image and volume framebuffer sizes. Orthogonal X/Y/Z slices sample their declared planes directly and have plane-local pan/zoom and exact hover sampling. The preview remains a bounded cube rather than a streaming volume.

The large authoring/stage batch is documented in [AUTHORING_AND_STAGES.md](AUTHORING_AND_STAGES.md). Noise reuse is conservative about UUID-dependent seeds and external identities; voxel reuse preserves semantic IDs. Curve metadata remains display-only, and stage ghost indices remain renderer-only. The batch is validated at completion rather than through alternating implementation/test cycles.

The streaming/runtime batch implements the scoped contracts in [STREAMING_AND_LOD.md](STREAMING_AND_LOD.md). RegionResult is now an owned AutoCloseable class rather than a record; constructors/accessors/value equality are preserved, while record patterns/reflection require migration. This API change is deliberate during development.

The world-use batch is described in [WORLD_USE.md](WORLD_USE.md). Placement programs preserve ordered floating-point evaluation. Y-dependent 2D sampling bypasses the column cache; 2D projection ignores an unused Y component while 3D references validate it. New format-2 fields have defaults and are optional in the structural schema. Trace records gained components with their prior constructors retained; record-pattern clients must account for the extended shapes.

The compiler/batch extension is documented in [COMPILED_EXPRESSIONS.md](COMPILED_EXPRESSIONS.md). Public expression input providers must remain immutable during one evaluation; successful values can be shared within that sample. Existing valid sampler-grid calls retain their layout/numerical order. Invalid coordinates/counts/strides now reject before writes; numerical failures preserve a successful prefix and report index/XYZ/cause. This is primitive CPU scheduling, not SIMD or a certified speedup.

The exact-storage batch adds per-chunk/local palettes, bit packing, compact immutable region replacement and archive v2 with v1 read/write compatibility. The format registry and independent binary vectors document the wire contract. See [EXACT_STORAGE.md](EXACT_STORAGE.md). Mutable in-place staging and representative hardware certification remain outside this extension.

The diagnostics/recovery extension retains candidate source locations and innermost compiler failures, bounded thread-safe grouped events and clipped native result lists. Navigation preserves the current rejected draft and uses project-scoped UUIDs rather than replaying old array indices. Read, resolve and dismiss are separate notification actions; bounded history may evict older groups. No project or preference schema shape changed. See [DIAGNOSTICS_AND_RECOVERY.md](DIAGNOSTICS_AND_RECOVERY.md).

The numeric-parameter extension adds a 32-row ordered mapping list for threshold/baseHeight/heightScale. NumericDriver permits finite signed endpoints; the existing probability/strength fields retain their base FieldDriver shapes and unit ranges. Relevant rows execute before interpretation, and per-row traces retain authored indices. Format 2 defaults to an empty list for historical projects; the world registry is version 3. See [NUMERIC_PARAMETER_DRIVERS.md](NUMERIC_PARAMETER_DRIVERS.md).

The scheduling/cache extension adds bounded weighted queued service and per-world round robin, shared promotion, disposable cancellation callbacks and cancellable asynchronous collection cleanup. Cache policies now distinguish global MEMORY_CACHE, locally bounded automatic caches and explicit USER_MANAGED retention. Cache byte accounting adds a 128-byte entry allowance. Prior RegionRequest/CacheStats constructors remain, with new record components requiring record-pattern/reflection migration. See [SCHEDULING_AND_CACHE_ADMISSION.md](SCHEDULING_AND_CACHE_ADMISSION.md).
