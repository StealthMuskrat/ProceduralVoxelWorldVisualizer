# Theme workspace ownership and recovery

Status: implemented on `codex/development-phase`, uncompiled and untested. Compilation, native probes, independent checkers and GitHub testing remain deferred by owner instruction. Historical theme evidence applies to its recorded baseline.

## Live preview ownership

A private ThemeEditSession retains its immutable opening palette and draft. ThemePreview separately owns the opaque token returned by its last ThemeStyle publication. Unchanged frames/equal palette values do not reinstall the style. When active theme values change or another ThemeStyle application replaces the token, the private preview pauses and retains its palette. A newer style owner remains untouched. If the preview still owns native colors when its saved base changes, it restores the latest active palette and releases ownership. Invalid in-memory active values pause safely and restore the valid opening palette without repairing user preferences.

Resume Preview explicitly reacquires the native style while retaining the private palette, and is offered only while the opening active theme values still match. A stale base requires explicit Revert Theme, which reloads current active values before resuming. Failed Revert retains its old draft. Restoring an old active value alone does not automatically resume a paused preview. Reset to Default and starting-appearance choices remain private edits and do not implicitly resume a paused preview. Closing consumes the preview and restores active colors only when its own native token is still current; repeated close/refresh cannot overwrite a later owner. This token is editor-thread state, not a lock or support for concurrent native access. Direct third-party ImGui color writes that bypass ThemeStyle are outside its detection scope, as is reusing a panel across native context destruction/recreation.

The inspector still pushes its independent readable Dark palette before Begin, including the window decoration and all child controls. It pops those guards before applying an explicit Resume/Revert or publishing changed preview colors. This ordering keeps style-stack restoration from undoing the newly requested palette. The authored sample intentionally shows the private colors, including low contrast or transparency. Collapsed or window-X content does not process controls, filter rows or contrast audits. Live ownership reconciliation still happens while collapsed; closing discards the draft. The native lifetime fixture uses collapsed/open flags rather than actual OS title-bar clicks.

## Feedback and publication

ThemeFeedback retains one immutable resolved map and complete contrast audit for the exact palette values; equal-value drafts reuse them, and status-only changes also invalidate the audit. Resolution/audit failures cannot publish partial results under a newer palette. Row edits refresh feedback in the same draw before the contrast view. ThemeRows caches immutable filtered projections by normalized query/group, combining palette colors and the four status roles with stable non-positional keys. Fixed two-control rows are clipped with horizontal scrolling. No broad hardware latency or total-allocation guarantee is claimed.

Save Theme checks the complete displayed palette and current active base before the existing staged preference writer publishes. Paused/stale previews disable Save; failed writes retain the draft, preview owner and retry state. Latest unrelated workspace, shortcut and scale preferences merge through the existing writer. The Desktop host routes bounded non-null failure details to `THEME_EDIT_FAILED` in the shared Application Error Center. Revert and starting-color/default actions remain explicit private changes. Successful publication starts a clean theme baseline. User Config format 1, palette registry 1, schemas, contrast formula and headless APIs are unchanged. The existing UserConfig replacement implementation is retained; unsupported-filesystem and power-loss guarantees are not expanded by this work.

No project resource, provisional Properties seed, document revision, dirty state, history or deterministic engine result derives from native theme colors. The new services remain in editor-ui.
