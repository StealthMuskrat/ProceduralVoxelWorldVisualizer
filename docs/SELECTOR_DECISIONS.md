# Resource and local-choice decisions

Status: **uncompiled and untested** on `codex/development-phase` under the owner testing pause. This follows [selector layout](SELECTOR_LAYOUT.md), [local choice popups](DRAFT_POPUP_LAYOUT.md) and [Properties decisions](PROPERTIES_LAYOUT.md). The validated baseline remains 922 tests / 120 suites.

ResourcePicker and DraftChoicePicker now collect at most one displayed selection, with None preceding authored result rows. They recheck the review, consume it, close the old popup and unwind the clipper/child/popup/ID scopes before invoking the callback. Callbacks therefore run in the caller's original native context. There is no remaining old-popup cleanup after a callback that may explicitly request another selector. Successful completion releases the consumed owner/source references while preserving the widget's private query and projection cache.

SelectorSession separates an opened request from its displayed row review. Opening ownership includes document/project identity and revision when available, explicit parent identity/version, current value, resource kind and nullability. Changes to those values close the former request and require explicit reopening. A skipped source frame or a native frame-counter restart also retires it. Each picker instance and opening has scoped row IDs, so reopening or replacing a picker cannot adopt an older held release. Escape suppresses both opening and selection and never chooses None or a first result.

Exact raw query spelling, None caption and immutable displayed source values belong to the row review. Query or source-value changes refresh that review and its native row IDs while retaining the popup and private query. Equivalent normalized search can reuse its projection without preserving the old raw-query gesture. Draft choices freeze values and detect an in-place list edit/reorder; equal rebuilt values retain their snapshot and IDs, accommodating callers that construct value lists during drawing. Resource choices retain the committed immutable index and perform their existing UUID/kind compatibility check. No callback identity is used as an owner because ordinary draw lambdas are recreated each frame.

Properties constructs both selectors with its current private draft and tracked edit version. A replacement draft or tracked nested edit cannot borrow an old field's choice even when its native label/current value/options are unchanged. Dependency resolution and resource deletion use their own session/form identity and current/stale eligibility. Global resource selectors remain independent of unrelated Properties drafts while retaining document/catalog ownership. The existing state-free DraftChoicePicker constructor retains supplied-value/native-widget ownership; it has no document authority or application log sink. Its private retry feedback is still available. No parent Apply, compatibility rule, inheritance reset or project save authority moves into a picker.

RuntimeException callbacks are contained after native cleanup. State-bound pickers retain required APPLICATION logs under RESOURCE_CHOICE_FAILED or DRAFT_CHOICE_FAILED, with detail bounded to 1,024 UTF-16 units and an exception-class fallback for blank messages. A failed unchanged review reopens on the next consecutive source draw with its query and scrolling failure detail retained, new row IDs and no automatic callback replay. Changed owner/value/query/source data or an omitted frame drops that retry. An explicit callback-requested successor opening wins over the old failure. A successful predecessor also cannot consume a successor. This does not roll back callback side effects; partial mutations remain the parent callback's responsibility.

Query fields, popup IDs and scrolling child identities stay on their stable paths. Presentation versions surround only None/result widgets. Result rows now use explicit single-line hit heights, whole-pixel clipped strides and tail items. Complete labels/keys/UUIDs remain in clipped-label tooltips. Per-widget query caches retain the existing 128-entry bound. Ordinary bookmark selectors and inline combo boxes are outside this batch.
