# Scalar surface display LOD

Streamed Isosurface now uses the same nearest-chunk-AABB distance rings, configured quality, hysteresis and pressure LOD bias as the other chunk scenes. Canonical corner grids remain immutable and independent of display quality. Camera/quality changes remesh those cached values; they do not compile a different field or regenerate its samples. Fixed analysis and the historical surfaceMesh(token) overload retain the original full-grid marching-tetrahedra path.

LOD0 is byte-identical to the prior extractor. At display level L>0, a chunk partitions into cubes of side 2^L. Each coarse cube connects its integer center sample to the two canonical triangles of every unit square on its six faces. These nonoverlapping tetrahedra fill the cube. Face diagonals use the same positive-axis unit-square diagonal as LOD0. All face nodes and center nodes come from the already sampled canonical grid.

Two neighboring coarse cells therefore share the same face triangulation and canonical values. The same holds between chunks at arbitrary different detail levels: the larger face still contains every unit triangle submitted by its finer neighbor. Canonical endpoint ordering and finite interpolation retain identical face crossings. No neighbor halo, balancing job, artificial boundary cap or transition skirt is needed. Normals stay per-triangle; this proves shared geometry, not smooth cross-LOD shading. Packed surfaces retain 1/128-block coordinates and the existing 1/256-block per-axis rounding bound.

This deliberately retains face detail while coarsening interior interpolation. It does not apply voxel majority aggregation to scalar samples. Small interior features can disappear or change shape under display approximation; authoritative samples and engine/project/archive results remain unchanged. Actual triangle counts need not fall monotonically at each level, since a different center/face sign configuration changes which tetrahedra cross the surface. Full-grid analysis remains available. Plane and nonlinear shared-face checks document the observed geometry rather than promising a general frame-rate improvement.

For root size n and coarse step s, there are (n/s)^3 cubes, 12*s^2 face tetrahedra per cube and at most two triangles per tetrahedron. The float output bound is 2016*n^3/s bytes; LOD0 retains 1008*n^3. Level 1 has the same worst-case cap as LOD0; subsequent caps halve. Admission retains geometric growth/final trimming, a complete sampled grid, packed conversion/copy space and fixed staging. The root remains 2..256 and power-of-two, and L is bounded by log2(n). Output caps and row cancellation apply before complete immutable mesh publication.

Scene signatures include scalar detail level, so a distance/quality/pressure change schedules a new bounded mesh. GPU publication still owns the accepted version: incomplete uploads preserve its previous level, geometry and position scale. Arena compaction retains level metadata alongside the existing units-per-block. drawnDetailLevels() reports only complete nonempty, visible submitted residents; removal/epoch reset clears them. Scalar surfaces still do not provide World voxel picking cells. Publishing a complete fixed mesh/image retires its now-hidden packed arena and clears drawn metadata; pending fixed work keeps the previous display. Clients reacquire the renderer through scene() when streaming resumes.

ChunkScene.Upload gains a level component. The historical five- and four-argument constructors remain; the cells constructor infers voxel LOD when present, and unidentified legacy uploads default to 0. Record-pattern/reflection clients must account for the new shape. SceneChunk adds explicit surfaceMesh(level,token) and surfaceWorkingBytes(size,level) overloads while retaining historical admission behavior, including the old bound helper's size range. These are renderer APIs; no persisted schema or engine API changes.

Validation includes exact LOD0 equality, independent affine areas/normals, mixed-level face segments on all axes, signed chunks, nonlinear boundaries, closed-sphere edge incidence, immutable concurrent remeshing, extreme/tiny finite values, root-256 packing, byte rejection/cancellation, and scene admission recovery without resampling. Native probes compare complete plane framebuffers against LOD0 during mixed uploads, indirect draws and bounded compaction in normal and actual strict OpenGL 3.0 contexts. Production Viewports checks camera/quality changes, negative travel, manual mode, fixed-analysis return, source epochs and authored/preference ownership. Representative hardware performance, sparse volume residency, shadows and full GUI/DPI/Windows 11 acceptance remain separate.
