Apply retains the existing validated one-transaction parent publication, including rejection of invalid raw seed text. Show Problems returns to that same feedback without restoring text, navigating to a different resource or committing anything. A transient PropertyActionOwner tracks the committed project object/lifetime/revision, exact draft object, active UUID/kind, selection count/sole-owner eligibility and private-editor blocking state. This presentation version scopes footer IDs only; it is not serialized and does not replace any model validation. New/reverted/same-UUID replacement drafts, another selection, committed changes, or private-editor entry/exit advance the version. Ordinary private value/raw-text edits, body scrolling, scale changes and rejected Apply retries retain it. Multiple-selection bodies are read-only, so the frame check uses constant-time count/active-owner checks rather than copying a large sibling list every draw. A changed owner discovered while drawing cannot submit the previous body's actions.

The footer collects all actions before publication. Revert takes precedence over Apply if both are requested, and Escape suppresses both mutations without implicitly discarding the parent draft. Apply/Revert are disabled while Curve, Membership, Noise resolution, Expanded Expression or a source-navigation guard is owned through the existing searchBlocked policy. Their opening/closing receives a new footer scope even when the parent draft object stays the same. This prevents a held predecessor action from publishing into a new context. Private editors keep their existing independent staging/cancellation semantics.

Moving the fields into that child changes their native ancestry once relative to the previous root layout, while logical field/UUID/focus keys and diagnostic routes remain.
