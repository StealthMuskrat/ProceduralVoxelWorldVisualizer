# Find and Trace footer decisions

Status: **uncompiled and untested** on `codex/development-phase` under the owner testing pause. This follows [Find and shared trace workspaces](FIND_AND_TRACE_LAYOUT.md), [diagnostic footer decisions](DIAGNOSTIC_DECISIONS.md) and [Inspector pages](INSPECTOR_LAYOUT.md). The validated baseline remains 922 tests / 120 suites.

Find collects Go To Selected, Show Filters/Results and Clear Filters before accepting at most one action in displayed order. Escape suppresses that frame's footer. Footer presentation IDs include a per-panel UUID and a version scoped to the document lifetime/revision, selected committed hit, raw query spelling, complete normalized filters, section and navigation availability/pending state, including an open private editor that blocks navigation. The post-draw check re-reads those values before acting. Closing, hiding or collapsing Find releases its action scope. Body/field/result IDs remain on their existing paths; cached committed search and actual-hit selection, row-click navigation and the pending draft guard remain authoritative. Filter changes retain an owned selection; explicit Clear still resets all filters and returns to Results. The ordinary search index can reuse a normalized query without granting its predecessor's footer gesture authority over changed raw text.

Trace collects both persistent action rows before copying, requesting a source link or changing page. Escape suppresses the complete footer and accepted actions follow displayed order. TraceActionScope records exact snapshot, document lifetime/revision, step, original selected observation row, raw query, displayed page and navigation eligibility/pending state. Native action IDs include the TracePanel instance UUID and admitted context version. Query spelling changes retire the old gesture even when TraceObservationSelection reuses its normalized projection and immutable Row. Page, selection, step and snapshot replacements also retire it. Source actions are disabled while a private editor blocks navigation or the shared navigation service already has a pending request; copy and paging retain their existing read-only behavior.

One shared TracePanel may be drawn in Logs and Notifications during the same native frame. Each native host has its own context/version and last submitted frame. Consecutive submissions retain IDs; a skipped frame retires only that host when it returns. The other host cannot keep the hidden presentation alive. Stale host slots are pruned on submission, including native frame-counter restart. This avoids unconditional release from TracePanel.hide, which is also used for snapshot observation before a visible Inspector draw. Snapshot/query selection refresh and current hidden-snapshot checks remain unchanged. The map retains only hosts submitted in the current or immediately preceding frame.

Accepted trace source requests retain the existing snapshot fingerprint, exact observation/query review and draft protection, with an additional document-lifetime check for both voxel and observation links. Hiding a view alone does not cancel an already admitted source decision. Observation decisions reject changed query/selection as well as changed document/snapshot; voxel decisions retain snapshot/fingerprint/document ownership independently of the selected observation. An unrelated active-source edit remains governed by the existing fingerprint review. Footer versions do not replace the underlying SearchNavigation transaction checks.

Trace footer RuntimeExceptions, including injected clipboard failures, are contained after collecting the complete footer. A bounded required APPLICATION entry under TRACE_ACTION_FAILED retains the failure detail (or exception class name when blank). No unrelated successor receives stale inline feedback. A handled clipboard failure retains its immutable reviewed value and footer IDs for retry; copying still returns the complete value or trace, independently of the displayed Unicode-safe page. This does not roll back any source navigation already accepted before a later reveal failure. Exceptions from later guard decisions and Find's existing property/reveal path remain outside this footer boundary.
