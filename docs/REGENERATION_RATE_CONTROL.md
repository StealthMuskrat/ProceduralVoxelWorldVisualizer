## Pair the live rate slider with exact text

User Settings > Editor previously exposed regeneration opportunities per second only as a full-width slider. It now uses the shared exact integer slider/text pair over the existing complete domain 1–20. The measured pair places editable text to the right when space permits and stacks it otherwise. The slider uses exact integer offsets and cannot open a separate rounded native text mode. The primary label and the meaning of regeneration opportunities remain unchanged: idle opportunities do not submit new generation, and only dirty selected data/dependencies require regeneration.

RegenerationRateInput owns the exact raw spelling and the last accepted active rate. Complete signed decimal integers in range update User Config immediately, including leading-sign/zero spellings such as +0007. Redraw does not canonicalize that spelling or write a value. Empty/incomplete, fractional/exponent/whitespace, overflowing and out-of-range text remains visible, displays a non-color error and disables only the slider. The active preference stays at the last accepted value, which the message identifies. Text remains editable for correction; Restore Active Rate discards rejected spelling without changing the active preference.

This is an immediate preference rather than an explicit-Apply project draft. Save Preferences writes current accepted User Config and does not adopt or discard rejected rate text. A human typing a valid prefix can update the live rate before later characters make the text invalid; the retained value is the last complete valid rate. Project/private Properties input, raw project seed input, document identity/dirty/history, engine ownership and generated values remain separate.

Hiding the Editor page retires its native numeric identity while retaining same-owner raw text. Reopening gives the pair a new identity so a held slider cannot continue on the successor presentation. Ordinary own edits and layout reflow retain IDs. Replacing the active Editor preference object or externally changing its rate installs fresh authoritative spelling/identity; a stale editor callback cannot overwrite that source. Restore also retires the previous numeric identity. The existing Save Preferences footer owner and immediate checkbox/display preferences keep their established behavior.
