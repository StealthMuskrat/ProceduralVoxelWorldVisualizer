# Shared numeric metadata guidance

Status: **uncompiled and untested** under the owner testing pause. This closes a scoped specification 4.1.3 / 5.2.3 / 6.1.2 integration gap in the existing Properties numeric pairs. It does not certify universal numeric presentation, every metadata caller, full native interaction, Windows 11 or release readiness.

Previously a registry numeric row's text field received its configured metadata tooltip and right-click Help, while the slider received only a hardcoded exact-value/range hint. Source rows also submitted competing tooltip replacements, allowing a generic creation-control tooltip to obscure the canonical source parameter help. Pinned numeric parameter copies did not attach the same metadata guidance to their original-control pairs.

`UiFields` now offers an optional per-part guidance hook after the slider and after the exact input. Existing callers without metadata keep their original behavior and widget IDs. Geometry and active-slider ownership are captured before the hook can draw a tooltip or popup. Properties routes source algorithm parameters, ordinary transform/processing parameters, numeric warp controls and individual non-constant numeric parameter pins through that hook. Choices retain their existing metadata path. Dynamic typed literals/shared values, World/Curve/view controls and the remaining metadata audit are outside this scoped integration.

Both parts read the same current AppMetadata topic, retain configured text verbatim and add the exact double value plus explicitly suggested slider bounds. Known topics offer right-click Help; missing topics get honest value/range guidance without an unavailable Help action. Blank configured text still exposes the known topic. Native IDs are included in distinct popup identities, so slider and text do not reuse one popup owner even when they share a logical topic. Disabled invalid numeric sliders can still expose guidance and Help; this read-only action cannot repair or publish their value. Tooltip text is constructed only when hovered and continues through the bounded, unformatted, inherited-font UiTooltip path.

Default source-parameter tooltips now derive their semantic help and true engine bounds from NoiseAlgorithmRegistry for both dimensions. Creation preset bounds remain separate from engine bounds and the visible suggested slider range. AppMetadata overrides continue to control presentation and Help; existing project values, compiler validation, signatures, creation values, option keys and resource UUIDs remain independent. There are no schema/format/engine/API changes and no generator execution.

Eight deferred NumericGuidanceTest definitions cover the complete dimensional source-parameter metadata projection, literal configured text and canonical topic identity, exact-double/signed-zero/extreme values, missing/blank controls, distinct unsigned native popup IDs, immutable guidance snapshots/live subsequent metadata reads and fallback topics for source/transform/warp/remapping. No definitions have run.

The existing deferred PropertyNumericProbe is extended through the actual source, translate, warp-amplitude and remap-input controls. For both slider and text it defines configured Unicode/percent/hash tooltip observation, right-click Open Help, exact topic delivery and complete Help-copy receipts, while requiring private/committed values to remain unchanged. Its original 84 layout cases and private Apply/Undo/Redo replay remain. The future verify_property_numeric.py replay requires all eight part/topic receipts and checks complete configured Help text. Existing manual workflow commands/artifact directories already include this probe; no workflow wiring or execution is added.

Only source inspection, Java formatting and git diff --check are performed. Compilation, Gradle/JUnit, native probes, receipt scripts, generators and GitHub workflows remain deferred. The observed baseline remains 922 tests / 120 suites.

The unvalidated [World metadata follow-up](WORLD_METADATA_GUIDANCE.md) extends the same numeric-part hook into fixed World property families and adds signed-int and exact-seed guidance paths. Non-numeric World controls, root headers and inherited/override/reset surfaces use corresponding read-only topics. Dynamic typed literals, Curve/view-specific metadata and remaining caller audit/acceptance stay separate; new definitions remain deferred.
