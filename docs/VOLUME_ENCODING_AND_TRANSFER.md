# Volume encoding and transfer

Sampled volume textures now retain a finite affine encoding. Ordinary magnitudes keep their existing raw float texels. Large or tiny values use a canonical offset and positive scale so their contrast survives texture conversion, including adjacent large finite values and subnormal constant fields. A range spanning opposite double extremes uses a zero offset and magnitude scale to avoid overflowing its span. The immutable encoding also retains canonical minimum/maximum bounds for CPU reconstruction.

`VolumeData.copySamples()` returns owned **encoded** float texels; renderer consumers must apply `encoding()`. The historical float `get()` remains a saturated accessor. `value()` and `interpolate()` reconstruct canonical doubles from display precision and clamp numerical reconstruction to accepted field extrema. Float textures remain a display approximation; a single texture cannot preserve an arbitrary mixed double dynamic range. The procedural sampler is unchanged.

Display minimum/maximum, opacity and threshold stay as validated canonical controls. Finite GPU gain/bias/threshold coefficients derive from those controls and the accepted texture encoding at render time. Scaled differences handle overflowing finite ranges; coefficients saturate outside representable float bounds rather than passing infinities/NaNs to shaders. Centered extreme textures preserve neighboring finite range endpoints. Threshold comparison occurs in texture space separately from color normalization, retaining tiny negative signs even under huge display ranges. Opacity retains its existing 0..10 effective range. Control changes do not request new field sampling.

Ray-box intersection handles parallel axes explicitly, including boundary rays, misses and cameras inside the cube. It no longer substitutes a positive epsilon for a small negative direction. Beer-Lambert integration still uses bounded 16..512 midpoint steps and low-transmittance termination.

Sampling now accepts the viewport's owned cancellation token. It validates finite origins and canonical samples, checks cancellation before allocation and on sampling/encoding rows, and publishes only a complete private snapshot. The legacy sampling signature still observes thread interruption. Sampling owns one double source array and one float texture array at peak (12 bytes/cell), preserving the existing working-memory admission estimate without an extra float clone.

Unit coverage checks ordinary layouts, immutable ownership, large offsets, opposite extremes, subnormals, cancellation/failure, exact transfer endpoints, threshold order and finite coefficients. Native reference cases use compiled project fields and production GlViewport. Twenty cases compare center pixels against independent homogeneous/linear optical integrals, covering extreme/tiny/neighboring ranges, threshold filtering, camera slab cases and opacity changes without resampling. Python independently uses Decimal arithmetic and saved field/texel/encoding/ray data.

This is bounded volume analysis. Streaming volumes/isosurfaces, the complete Volume toolbar and physical GUI/DPI/Windows 11 hardware matrix remain separate.
