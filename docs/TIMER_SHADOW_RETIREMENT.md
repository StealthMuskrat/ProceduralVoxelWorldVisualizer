# Timer and shadow resource retirement

W06-C22 reconstructs child resource ownership in 1.4.1/14.1.5, display lifetime in 15.5.3 and optional GPU observation in 19.4.2/19.4.4. The restored timer swallowed only RuntimeException during release, detached one slot at a time, and could overwrite CLOSED or reattach a returned query after a callback. Shadow close deleted sequentially before zeroing fields and also served as a reusable resize operation. This reconstruction follows [workspace recovery](WORKSPACE_RECOVERY.md), without claiming original commit recovery or runtime validation.

## Timestamp ownership

GpuTimerQueries now captures and clears the entire four-pair ring, active pointer, scopes and slot metadata before whole-pool deletion. Query names use the existing typed RenderRetirement helper with a new QUERY namespace and glDeleteQueries dispatch. Nonzero signed names remain valid; aliases coalesce within the query namespace only. Every captured deletion is attempted independently, and ambiguous effects are never replayed. Expiry detaches its pair before deletion; a failure then retires the remaining ring without replacing the first failure.

Close publishes CLOSED/disabled state before callbacks and remains terminal even when deletion fails. It exposes the first cleanup RuntimeException/Error after all attempts. Stop and capture replacement settle logical admission before retirement; optional RuntimeException failures suspend measurement with a fixed status until another capture, while Errors propagate after cleanup. Work RuntimeExceptions remain optional failures, work Errors retain identity, and later cleanup failures cannot replace either. Failure handling does not inspect throwable text or add suppressed failures. Capture replacement resets counters without charging old pending discards to the new capture; ordinary same-capture opt-out keeps capability/counter history.

Begin/end/poll/synchronize serialize callbackful work on the render thread. Recursive work returns zero/empty/no-op rather than stealing an active pair or changing its capture. Close is still allowed during work. Generation checks after backend, clock and profiler admission boundaries stop further commands/publication after closure. A query returned after close is retired as an unregistered candidate; a backend allocation that throws before returning a name cannot transfer that unknown handle and remains backend responsibility. Signed/duplicate-name definitions cover logical retirement, not endorsement of a backend returning aliased live allocations.

Poll captures issue/capture/label/outcome/width primitives and consumes the slot's pending metadata before calling recordDuration. A closed operation cannot append a later Measurement receipt or mutate replacement counters. The profiler API still owns capture limits and admission; a duration already submitted through that API is not rolled back. There is no new synchronization, wait loop, query-result read before both availability flags, glFinish, larger ring or changed timestamp arithmetic. Full viewport frame/timing acceptance remains C24 work.

## Shadow ownership

GlShadowMap delegates actual texture/framebuffer/program/resolution ownership to ShadowResources. Release captures three typed names and zeros all fields before callbacks; every namespace is attempted independently even when numeric names coincide. Resize uses reusable release, while public close marks ownership terminal before release. Work rejects while closed or retiring, getters expose zero after retirement, and repeated/nested close cannot replay deletion. A nested close during resize cannot reopen the owner.

Allocation's body RuntimeException/Error retains priority over failed candidate cleanup; the owner remains available for explicit retry after reusable release. Subsequent [C23 reconstruction](SHADOW_STATE_TRANSACTIONS.md) replaces sequential allocation/raster finally blocks with independent state tails and candidate/pass acceptance, also awaiting execution. C22 alone does not restore those transactions. After a normal draw callback returns, render also rejects a now-closed owner before returning a draw count.

GlViewport detaches its timer before clear-time close. Shadow work failure detaches/closes its captured child independently, preserves a fatal Error, and retains optional RuntimeException fallback with a fixed retry message rather than executing exception text during cleanup. Root/native sibling ownership remains [C20](NATIVE_RENDERER_SHUTDOWN.md); UI peer shutdown remains [C21](UI_PEER_SHUTDOWN.md). Driver release before-effect failures may leave physical residue, and no cleanup retry or reclamation certification is introduced. Fixed small retirement allocations and callback guards are unmeasured.
