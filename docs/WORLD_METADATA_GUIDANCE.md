# Configured World guidance and context Help

Status: **uncompiled and untested** under the owner development-phase pause. This implements a scoped specification 4.1.3 / 10.2–10.5 guidance integration across the existing World Properties controls. It extends [World numeric controls](WORLD_NUMERIC_CONTROLS.md), [numeric metadata guidance](NUMERIC_METADATA_GUIDANCE.md) and [World setting focus](WORLD_SETTING_CONTROL_FOCUS.md). Source coverage is not full GUI, schema, Windows 11 or release acceptance.

Previously World numeric pairs exposed a generic value/range hint on their sliders, with no configured World guidance or context Help on the text side. Non-numeric controls, setting headers, live inherited values and Override/Reset also lacked a consistent World metadata route. This made exact inheritance, interval endpoints, signed-axis sampling, indexed driver targets and previous-state predicates difficult to discover where they were edited.

WorldControlMetadata contributes 32 presentation-only AppMetadata topics: one for each of the fixed 28 inheritable properties, plus enable state, placement source, interpretation and live inheritance. Descriptions state the existing pipeline semantics, including field >= Threshold for Selection/Density, floor(height + 0.5) for ROUND, interval no-match NO_CHANGE, EMPTY exclusion from occupied type/set tests, driver phase/range rules and positional transform indices. The root property is the metadata identity for every nested row in its family; indices never become metadata keys or navigation targets. This lookup offers a family guide and does not claim that an arbitrary row/leaf exists in a live draft.

Existing World field labels, control ordering, widget IDs, focus routes and execution settings remain authoritative. Application Settings identifies these entries as Help names/tooltips/descriptions, with no creation-default or option remapping authority. Private metadata edits reach active Properties and Help only after their existing Apply action. Legacy profiles merge the new built-in guides. The app-config schema explicitly allows the new keys, preserves empty option whitelists and excludes them from creationDefaults. Its format remains 1; older binaries can reject the newly published unknown control keys. Project/model/engine/API/archive formats and dependencies are unchanged.

Ordinary scalar and signed-int pairs now attach the same configured guide, exact value/range text and canonical Help topic to both native parts. The shared integer drawer gains the same optional guidance hook as its scalar counterpart; default callers keep their existing behavior. Exact signed-long World and gate seed pairs use a raw-string guide on both parts, never a double conversion. Invalid seed text stays in its existing owner and disabled sliders can still expose read-only Help. The bounded exact-long helper preserves its original overloads, default neighborhood tooltip, raw validation and focus callback for other callers.

Boolean/choice/resource controls and root setting headers expose their family's configured tooltip and Help. Placement enable/source/interpretation use their own guides. Unchecked live values retain their whole numeric value in hover details and open the same property guide; Override and Reset open the inheritance guide. Reading Help never enables an override, resets it, applies a draft or saves a project. Source geometry is captured before optional Help popups, and actual native IDs distinguish slider/text popup ownership. Collection structure changes retain their existing native scope/version rules.

The new World controls and live inheritance manual topic links these guides to layers, ordered settings, condition trees and scalar readouts. Help copies/searches include active configured text and complete descriptions. Existing UI tooltip clipping, safe unformatted text, inherited fonts and popup work-area fitting remain in use; no metadata string becomes a computational expression or field value.

Ten deferred WorldControlMetadataTest definitions cover all canonical roots, nested/reordered family routing, override/reset/placement subjects, unknown scope versus family-only guidance, legacy/partial profile merging, private metadata publication without World changes, rejection of creation/option authority, exact high-bit/signed-long/rejected spelling, independently owned contributed controls/Help snapshots and explicit schema/catalog parity. The partial app-config-world-guidance.json fixture and future schema checks cover all 32 accepted subjects plus unknown controls, forbidden options and forbidden creation defaults. Schema/fixture changes are source edits; no generator or validator has run.

The existing deferred WorldNumericProbe now defines sixteen slider/text Help actions across threshold, signed minimum Y, sampling transform X, numeric-driver input/transform index, type interval minimum, gate threshold and exact seed offset. A private 9007199254740993 seed checks unrounded tooltip digits and is explicitly restored before the original Apply replay. Three more actions cover live inherited threshold, Override and Reset. Configured Unicode/percent/hash tooltips, exact topic delivery, complete copied Help and unchanged private/committed/metadata/history state are defined. The original eighteen layout scenarios and sparse Apply/Undo/Redo/reset/live-inheritance and independent engine replay remain. Its existing future receipt script now requires all nineteen routes and complete Help text. No new workflow or execution is added.

Only source inspection, Java formatting and git diff --check are performed. No compiler, Gradle, JUnit, native probe, engine consumer, receipt checker, schema validator/generator or GitHub workflow ran. The observed baseline remains 922 tests / 120 suites. Wider metadata callers, complete interactive/schema/platform/hardware and final release validation remain pending.
