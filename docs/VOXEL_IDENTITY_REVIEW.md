# Voxel identity review — unvalidated implementation

Specification 9.2.4 requires voxel semantic-ID changes to display existing dependencies and offer safe reference handling. Voxel Manager and Properties previously exposed ID edits without that explanation. Both now show a committed identity review: semantic ID, a different proposed ID where applicable, incoming resource UUID references, and an explicit explanation that a rename keeps UUID references while existing voxel archives keep their old semantic strings. Existing validated Properties Apply and inline Enter remain the reference-preserving rename choices; Revert/Escape retain the committed ID. There is no second identity field or hidden reference rewrite.

`VoxelIdentityIndex` captures immutable type names and incoming dependent resource descriptors using the recognized reference-key contract already used by deletion/clipboard/import. It lists membership groups/sets, layer defaults, containing layers and operation references, including authored disabled resources. Containing layers are disclosed explicitly rather than counted as separate direct usage locations. UUID-looking visible labels do not become references. It indexes committed definitions only and never evaluates or applies private draft input.

One EditorState-owned cache is shared by both views. Exact document-session, project-object and revision identity controls rebuilding; private ID/color edits, reflow and scrolling reuse it. Descriptors own their labels/lists, with no retained mutable resource nodes. The cache uses a weak source-project reference and clears on New/closure. A same-revision project or session replacement cannot reuse a predecessor index.

The manager reserves a bounded detail pane under its virtualized type rows; Properties provides an initially expanded Voxel Identity and References section. Each review has a scrolling body, clipped dependency rows and a persistent Find All References action routed to real unified Find. Action ownership includes the immutable type, proposed text, selected resource, draft identity and document/revision. Changed/hidden sources retire the action, Escape suppresses delivery, and callback failures remain bounded recoverable messages. Manager metadata is resolved again after row callbacks so a just-published rename is not displayed as its own predecessor proposal. Manager window focus also participates in existing resource keyboard shortcuts; Escape now cancels its inline rename input directly. Groups/sets retain their existing Find References entry point.

## Deferred validation definitions

Six `VoxelIdentityIndexTest` definitions cover exact group/set/layer/operation vectors, nested predicates and UUID-looking labels, immutable snapshots, cache source/session/revision/clear, private-draft exclusion, UUID-preserving rename and a 2,052-dependent fixture. `VoxelIdentityProbe` defines a real 2,051-dependent native workflow in both production hosts, six synthetic layout receipts, bounded scrolling with one shared index build, actual Find References callbacks preserving private ID/color input, Properties and inline text renames, duplicate-ID rejection, manager Escape and one Undo/Redo for each publication.

The independent Python checker compares entire before/after projects allowing only the expected single semantic-ID field to change, exact dependent UUID/kind/name order, complete preferences, requested Find targets and action geometry. Engine-only `VoxelIdentityConsumer` defines 567 exact constant samples and 1,008 generated cells across seven saved documents and signed/root-size cases. It also writes an original `stone` archive, rejects decoding it with the renamed-only registry, verifies that registry stays unchanged, decodes 64 cells as a different runtime ID using a compatible registry containing `stone`, and confirms the archive bytes remain unchanged. Future Linux/Windows commands and artifacts include these definitions; the workflow remains manual-only.

No compiler, JUnit, native probe, independent consumer, Python checker or GitHub workflow has run for this batch. The validated baseline remains 922 tests / 120 suites. Main is the sole branch. This is read-only disclosure plus existing validated publication, not an archive migration or a claim to enumerate external files. Index construction cost, every manager/rename/native gesture, physical DPI/input, full GUI/Windows 11 and final release acceptance remain pending.

Existing engine-consumer arithmetic is unchanged. These additional definitions have not compiled or run; physical creation/paste and Windows 11/DPI remain pending.
