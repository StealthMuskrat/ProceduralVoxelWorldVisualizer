# Bounded profiler captures

Development addition: [attributed layer/operation work totals](WORLD_WORK_CONTRIBUTIONS.md) are implemented but unvalidated while GitHub testing is paused. Earlier capture evidence below belongs to the validated baseline.

View > Profiler exposes live engine/scheduler/streaming statistics and one opt-in capture. Start Capture begins a fresh bounded history; Stop retains it; Clear releases the current capture. Closing the window leaves an active capture running until stopped or a limit is reached. Debug & Profiling's targeted-capture switch uses the same active capture. Capture controls and source navigation do not edit or dirty the project. No capture starts from a saved user preference.

The next-capture limits are visible in the panel. Duration is 100–60,000 ms, sample capacity 64–65,536, distinct-series capacity 1–1,024, and operation stride 1–65,536. Defaults are 10 seconds / 8,192 samples / 128 series / stride 256. Bounds apply across all threads and contexts sharing an engine. The collector stops rather than evicting earlier data. The attempted first new series beyond the limit is not retained. Time expiration is checked at observation/recording boundaries; no dedicated timer thread is created. Measurements finishing after a stop are discarded. Long-running work cannot extend retained duration beyond the configured limit.

A sample retains monotonic start offset, nonnegative value, explicit unit/outcome, engine-local context ID, snapshot project UUID, optional source UUID and chunk, bounded label, thread ID and bounded thread name. Labels/names retain at most 256 UTF-16 units. Snapshot lists are immutable. Series group by kind, unit, context, project, source and label, aggregating threads. They report count, min/max, arithmetic mean, P50/P95/P99 and failed/cancelled counts. Percentiles use nearest rank `sorted[ceil(p*n)-1]`; byte/count gauges are summarized in their own units.

| Measurement | Meaning |
|---|---|
| QUEUE_WAIT | Async shared-request admission-to-execution interval; includes dispatch delay. A queued request removed before execution produces no wait sample. Shared work produces one sample, including synchronous stealing of async work. |
| CHUNK_GENERATION | Admitted uncached chunk generation through successful publication/retention, or failure/cancellation. Cache hits and pre-admission rejections produce no generation duration. |
| FIELD_PREFETCH | Per-placement column-cache preparation, separate from cell operation timings. |
| OPERATION | Every Nth visited operation per capture/calling thread, including skipped placement predicates. Source is the placement UUID; label contains its layer and placement IDs. Sampling is workload-dependent and does not reconstruct exhaustive cost. |
| OPERATION_WORK / LAYER_WORK | Opt-in sums of visited placement and prefetch intervals per chunk/stage computation; implementation awaiting validation. Layers derive from the same operation intervals, so the two kinds overlap. |
| STAGE | Admitted exact before/after snapshot generation, including shared prefetch and both prefixes. Source is the selected stage UUID. |
| REGION_DELIVERY | Consumer invocation through acknowledgement, failure or cancellation. Does not include generation wait. |
| PREVIEW / MESH_CPU | Fixed-preview worker execution and streamed LOD/mesh worker execution; exclude background queue wait. |
| UPLOAD_CPU / UPLOAD_BYTES | Streaming CPU upload staging/submission interval and actual uploaded bytes per frame, including zero-byte frames. The CPU interval also includes bounded arena maintenance; a separate byte gauge reports relocation destination writes. |
| GPU_DRAW | Optional asynchronous timestamp interval for offscreen 3D viewport commands, including clear/resize, optional shadow depth passes and draw submission. See [GPU draw timing](GPU_DRAW_TIMING.md) for scope, capability and bounded query ownership. |
| FRAME | ImGui frame interval. |
| Memory / queue / GC | Editor gauges at most every 250 ms: JVM used heap and cumulative GC time/count; engine active workers, queues, cache/staging/collection admission; scene CPU resident+reserved and allocated GPU vertex arena capacity plus a separate Shadow depth-map allocation series. |

Except GPU_DRAW, durations are monotonic **CPU-side wall elapsed time**, including preemption and waits, not thread CPU consumption. Nested chunk/prefetch/operation/stage/preview timings overlap; adding them double-counts work. The development branch adds opt-in layer/placement work sums with a narrower attributed scope, separate from those overlapping timings; see [work contribution semantics](WORLD_WORK_CONTRIBUTIONS.md). GPU arena size is allocation accounting, not physical GPU residency. GPU_DRAW reports a separate timestamp interval; it is not total GPU frame time or exclusive shader time. Exhaustive thread traces remain outside this implementation.

Engine timings belong to the capture attached when the shared request/stage starts; starting midway through existing shared work does not retroactively capture it. Scope references never move into a later capture. Raw sample order is completion/publication order, not necessarily start-offset order. Captures from concurrent workers can therefore interleave. Neither timing nor sampling feeds back into noise or voxel results. With profiling disabled the engine takes a nullable scope path, without per-operation clock reads or capture allocations. During a capture, unsampled operations only check state and advance a thread-local counter; they do not read the clock or build labels. Stops use a volatile fast path.

Series can be filtered by kind and case-insensitive label/context/UUID search. The native list is clipped; snapshots/percentile aggregation refresh at most four times a second. Select a series to inspect its distribution. Go To Source is offered only for a resource UUID still present in the same project, using the existing draft-preserving navigation service. Historical labels do not retarget renamed/deleted resources.

JSON and RFC4180 UTF-8 CSV exports happen only on an explicit button/API call and include all retained measurements, independent of the panel filter. On the unvalidated development branch, Prepare Export freezes the displayed snapshot for explicit review; collection may continue, and failed writes keep that review through capture replacement or Clear. Choose the complete output filename in Export path; the JSON/CSV buttons use that exact path and consume the review on success. Prepare again to select the current displayed snapshot. The panel rejects the active project path and aliases. Writers create a temporary sibling, force its content and require atomic replacement; unsupported replacement fails without a non-atomic fallback. Headless ProfileIO callers still pass their own snapshot/path and do not have an editor project guard. Failures clean temporary output; exporting does not stop generation, autosave a project or create background logs. JSON is version 1 with a checked-in schema and portable fixture; CSV includes capture/state/time/source/chunk/thread metadata plus the original units.

Validation covers deterministic fake-clock durations/percentiles, bounds, stride and disabled clock work, capture isolation/lifecycle, concurrent publication, exact generation invariance, actual queue/stage/failure/cancellation/acknowledgement samples, export preservation/escaping and project-scoped UI navigation. The independent example compiles against only the published engine JAR and exports actual generation samples. Native smoke explicitly starts/stops a capture and exports real frame/heap data; it does not automatically enable profiling in normal startup. Native GPU timing validation additionally checks raw timestamp receipts, capture replacement/stop, timed/untimed framebuffer parity and production Profiler exports. Full interactive acceptance and representative hardware performance remain separate gates.

The export-review implementation and thirteen additional regression definitions, native production-panel scenario and independent replay definition remain uncompiled/untested under the owner testing pause. No current acceptance gate is advanced. See [profiler export ownership](PROFILER_EXPORT_OWNERSHIP.md).
