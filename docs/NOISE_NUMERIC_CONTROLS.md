# Paired noise authoring controls

Status: **uncompiled and untested** on `codex/development-phase`, under the owner's testing pause. The observed baseline remains 922 tests / 120 suites. This continues the [viewport numeric controls](VIEWPORT_CONTROL_PANES.md) audit against specification 4.1.2/4.3.3/5/6 and supports A10/A11/A32 without advancing acceptance status.

The noise Properties panel now uses one UiFields slider/text row for source parameters, ordinary processing parameters, coordinate-transform components, remapping controls, source and transform warp parameters, scalar/vector literal inputs, scalar/vector shared parameters and their pinned value editors, and sampled/reference field slice coordinates. Existing named-choice controls and separately owned signed-long seed fields retain their current paths. UiFields' original plain input remains available to other panels; World settings, curve controls and the remaining shared numeric callers are outside this batch.

Each row wraps its metadata label above the controls. When two fields of at least seven current font units fit, the exact input sits to the right of the slider; narrower layouts stack the fields without changing their keys. Source and warp controls use their registry preset ranges. Processing/transform controls use their dimension-specific CreationRegistry range intersected with [-1024,1024], or [-1,1] for an unregistered numeric control. Literal scalar/vector components suggest [-1,1]; inserted slice coordinates suggest [-1024,1024]. These are slider suggestions, not new engine or text-input limits. Transform controls now resolve their transform metadata key instead of a processing metadata key. Existing metadata Help and diagnostic paths remain.

Sliders show five fractional places, or zero for integer-valued controls, with native NoRoundToFormat and NoInput. Fractional scalar values are not rounded to the readout; an integer slider gesture explicitly rounds to an integral double. The adjacent existing input retains seventeen significant digits, including scientific notation, according to the [precision policy](NUMERIC_EDITOR_PRECISION.md). This does not certify universal five-place numeric presentation. Drawing a row does not clamp or rewrite an out-of-suggestion value. Invalid values entered in Properties retain the established private-draft and Apply-validation behavior; viewport finite-value rejection is not imposed on Properties.

The slider is submitted before invoking the caller's existing property/binding focus wrapper. Diagnostic navigation therefore still targets the exact text field and retains its acknowledgement, input-leaf and pin/source identities. If a requested property/binding input is clipped while scrolling toward it, its unacknowledged focus submission can retry once it becomes visible. Acknowledged, unrelated and retired requests cannot be rearmed by the property retry. No document transaction, navigation selection or preference is added by layout or focus. Slider and text edits call the existing private setter/change notification; Apply remains one validated project transaction.
