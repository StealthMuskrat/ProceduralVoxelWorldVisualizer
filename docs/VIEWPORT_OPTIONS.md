# Finite visualizer choices and Inspect opening

Status: **uncompiled and untested** on `codex/development-phase` under the owner testing pause. The validated baseline remains 922 tests / 120 suites. This extends [visualizer commands](VIEWPORT_COMMANDS.md), [selector decisions](SELECTOR_DECISIONS.md) and [stage boundary selection](STAGE_BOUNDARY_SELECTION.md). It does not advance A01–A36 or production sign-off.

Display, Representation, Slice normal and Stage preview now use ViewportChoicePanel. These are fixed small vocabularies of five, five, three and four values, with the existing exact labels/keys and order. A bounded PopupLayout scrolling child retains all choices at large scales. The trigger width is capped and the label wraps to a separate row when needed. Rows use explicit single-line hit heights, whole-pixel strides and clipped-label tooltips. Unknown/null current values show an unavailable preview without silently substituting another value. Numeric controls and their existing immediate view-state authority are unchanged.

Each control freezes its existing ViewportActionContext plus its own displayed current value. This separate field value matters for Slice normal: an axis change cannot borrow a held row even when the broader view context has not yet advanced. A per-instance trigger scope changes IDs when the document, source, epoch, modes, tab/surface, bookmark owner, owned preferences or field current value changes. Popup and scrolling child identities remain stable. The shared SelectorSession retires changed opening owners, versions reopened rows and consumes one reviewed choice before native child/popup/ID cleanup. Callbacks run only after those scopes unwind. Escape suppresses opening and selection. End-of-frame retirement releases controls omitted by a collapsed window, another tab or a hidden representation-specific field.

Runtime choice callback failures record bounded required VIEWPORT_OPTION_FAILED rendering diagnostics and offer an explicit retry of an unchanged review, with fresh row IDs and feedback. There is no callback replay. An explicitly requested successor opening wins over its predecessor's failure/completion. A source change during complete drawing rejects the pending choice. Choosing the currently selected value still completes the popup; Viewports avoids unnecessary preview invalidation for that no-op. Changed modes/axes retain the existing mark/epoch, camera and exact-generation authorities.

Inspect Coordinate now uses an independent source-owned ViewportCommands action. Complete button drawing, Escape precedence, live source recheck and per-instance/hidden presentation IDs protect its opening. A failed callback retains the unchanged explicit retry and records the existing VIEWPORT_COMMAND_FAILED diagnostic. Viewports routes the accepted action to the same Inspector-open flag, independent of whether a preview boundary is currently available. It does not trace a coordinate, select a cell, apply a draft, or change the document merely by opening. The original Inspector/trace task authority remains unchanged.
