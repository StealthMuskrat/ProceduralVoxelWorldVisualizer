# World setting control focus

Status: **implemented, awaiting validation** on `codex/development-phase`. The owner has paused GitHub testing until the program is fully developed. This source and its regression/native/independent replay definitions have not been compiled or executed. No prior acceptance status is promoted.

World-setting problem/source links now activate the control as well as showing its location. The route covers Layer Enabled; placement Enabled, Noise generator and Interpretation; all fixed top-level world-use settings; and the singleton probability/strength field-driver leaves. The root previous-voxel predicate and root field gate expose their conditional leaf controls through the same focus path. Custom UUID selectors acknowledge their actual button.

The existing owned Properties focus request remains one-shot: it belongs to the project, resource and exact private draft, submits once, scrolls to its widget and acknowledges actual focus. A replacement draft, another destination or Clear Location cancels it. If a pending route's effective condition or override presence changes before acknowledgement, the request is cancelled rather than redirected silently. A source link does not enable a layer, choose a field, change interpretation, edit a gate or publish a project transaction.

## Inheritance and conditional controls

An absent placement override has no editable local value. Its source link therefore focuses the corresponding **Override** checkbox and explains live inheritance. Navigation does not tick it or materialize a value. The user can explicitly enable it, which uses the existing deep copy of that layer property, and follow the value link to edit it. Explicit zero and false remain present overrides. A malformed stored override leads to its disable control; disabling restores inheritance.

A root predicate reference that is hidden by its current kind leads to Condition. A gate field hidden by its current kind leads to Gate. A fixed-voxel target hidden by interval type selection leads to Type Source, or its Override checkbox when that choice is inherited. No fallback chooses another kind or changes a value. Aggregate controls open and focus their existing section header. The header can be collapsed normally after focus acknowledgement.

## Logical paths and collection boundaries

Canonical links use `settings/property` and supported `settings/property/leaf` keys. Known `defaults/` and `overrides/` aliases are accepted. Structural diagnostics may supply a recognized suffix under a Layer's `defaults` or a placement's `overrides`, after ordinary resource UUID navigation has resolved the owner. Explicit qualified leaf keys take precedence over contradictory pointer suffixes. Resource/layer/operation array indices in historical pointers are never replayed against the current project.

Sampling-transform, numeric-driver and type-interval rows, and nested predicate/gate clauses, currently have positional identities. Links below those collection boundaries reveal the aggregate header without choosing an old row index. Root condition controls are distinct from controls in child clauses. This batch adds no persisted identities, new settings, schema changes or engine semantics.
