# Curve numeric controls and local slider history

Status: **uncompiled and untested** on main, under the owner's testing pause. The observed baseline remains 922 tests / 120 suites; the workflow remains manual-only. This continues [noise](NOISE_NUMERIC_CONTROLS.md) and [World](WORLD_NUMERIC_CONTROLS.md) numeric controls against specification 4.1.2/4.3.3/8 and supports A08/A13/A32 without advancing acceptance status.

Curve Editor domain/display endpoints, selected interior X, selected point Y, explicit incoming/outgoing slopes and local snap increments now use measured slider/text pairs. Exact inputs remain to the right when the current font and width permit; narrower layouts stack them. Logical field focus is submitted only at the exact input, after the slider. Clipped unacknowledged focus can retry after scrolling. Native keys include the dialog opening and, for point controls, the selected point UUID, preserving identity through reflow without reusing a predecessor dialog's gesture.

Domain suggestions use [-1,the next interior X] and [the preceding interior X,2], with strictly interior adjacent representable endpoints. Interior point X suggests the open interval between its neighbors. Y suggests the authored display range; slopes suggest [-16,16]; positive snap increments suggest [1e-6,1]. Display endpoints suggest a surrounding [-1,2] interval respecting their opposite endpoint. Native ranges intersect [-1e6,1e6], with that finite fallback when the intersection is empty. These suggestions never clamp stored or typed values, expand an invalid domain, unlock endpoint X, change interpolation or alter execution output. Existing curve validation remains authoritative. Scalar slider readouts use five places with native rounding disabled; exact text retains the [existing precision policy](NUMERIC_EDITOR_PRECISION.md). Universal five-place exact-edit presentation is still not certified.

CurveNumericGesture uses a package-local validated absolute-edit preview in CurveEditSession. Repeated accepted slider frames remain one pending local gesture; normal release commits the last accepted preview as one Undo entry. Invalid intermediate ordering/domain/slope edits retain the last valid preview and error feedback. Escape, application/window focus loss, collapse, disappearance or row geometry changes roll back only the preview still owned by that slider. Retired held input is blocked until release. A newer session edit cannot be rolled back or followed by that old held slider. Explicit local commands finish the owned numeric preview before their established Undo/Redo/selection/Apply action. Plot and numeric gestures retire one another before starting; exact text retains its existing discrete local edit path.

Aligned slope numeric edits update both slopes together. Domain numeric edits update the endpoint X with its domain boundary. Snap increments remain immediate dialog-local view values and do not create curve history. Curve Apply still stages one validated value in the original Properties draft; Properties Apply publishes one project transaction. Cancel, source/currentness checks, engine/model/storage/schema, preferences, public APIs and licensing retain their existing contracts.
